## Заявка: отсутствие действия удаления

**Проект:** Флэт, CRM.
**Раздел:** Карточка заявки.
**Тип теста:** функциональный, проверка прав доступа.
**Окружение:** test.
**Версия:** v.56e46cf9.
**Роль:** Администратор.
**ОС/Браузер:** Windows 11 / Chrome 140.
**Автор/Дата подготовки:** Юлия / 18.09.2025.
**Тип материала:** подготовленный сценарий; результат прогона не зафиксирован.

### Цель
Проверить отсутствие удаления заявки согласно бизнес-правилу, указанному в связанном баг-репорте. Проверку интерфейса дополнить проверкой ограничения операции на серверной стороне.

### Предусловия
- Пользователь авторизован как администратор.
- Есть тестовая заявка, доступная для просмотра.
- Для проверки серверной операции определены фактический запрос и ожидаемое поведение по контракту API.

### Шаги
1. Открыть карточку тестовой заявки.
2. Проверить верхнюю панель действий и меню карточки.
3. Повторить проверку на мобильной ширине окна.
4. Проверить отсутствие действий, удаляющих заявку целиком, в меню вложенных сущностей.
5. На тестовом окружении проверить, что операция удаления недоступна через фактический API-запрос.
6. Обновить страницу и проверить, что заявка сохранилась, действие удаления отсутствует.

### Ожидаемый результат
1. Карточка доступна для просмотра.
2. Действие удаления заявки отсутствует.
3. На мобильной ширине действие также отсутствует.
4. Меню связанных элементов не позволяют удалить заявку целиком.
5. Сервер отклоняет недопустимую операцию согласно контракту; заявка не удаляется.
6. После перезагрузки состояние заявки и ограничения сохраняются.

### Результат выполнения
В исходных материалах результат прогона не зафиксирован.

### Очистка данных
После проверки убедиться, что тестовая заявка существует и её данные не изменены.
